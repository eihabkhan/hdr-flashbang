# HDR Flashbang

HDR Flashbang transforms ordinary images into eye-catching, ultra-bright HDR emotes perfect for Slack reactions. Make your responses stand out with emotes so bright they practically jump off the screen!

## Features

- **One-Click HDR Infusion**: Transform any supported image with just one command
- **Slack-Ready Output**: Images are automatically sized and formatted for Slack emotes
- **HDR Color Profile**: Uses a professional HDR color profile to make images pop
- **Finder Integration**: Works directly with your selected files in Finder
- **No Dependencies**: Uses macOS built-in tools - no external software required

## Requirements

- macOS (uses native macOS tools)
- Raycast v1.50.0 or higher

## Installation

1. Open Raycast
2. Search for "Extensions"
3. Click "+"
4. Search for "HDR Flashbang"
5. Click "Install"

## Usage

1. Select an image file in Finder (supported formats: JPG, PNG, GIF)
2. Open Raycast and search for "Infuse"
3. Hit Enter to apply the HDR effect
4. The processed image will be saved with "\_hdr" suffix in the same folder
5. Upload the infused image to Slack as a custom emote

## Technical Details

HDR Flashbang uses macOS's built-in `sips` command to apply a specialized HDR color profile to images. The transformation enhances color vibrance and brightness without degrading image quality.

Supported image formats:

- JPEG/JPG
- PNG
- GIF
